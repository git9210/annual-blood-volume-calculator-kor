# 연간채혈량 계산기 2.1.1

헌혈 기록과 직전 1년의 계산량을 기기 안에서 관리하는 Android 앱입니다.
개인이 제작한 비공식 도구이며, 실제 헌혈 가능 여부는 기관의 문진·검사로 결정됩니다.

## 설치

배포용 파일은 `Annual-Blood-Volume-Calculator-2.1.1-Small.apk`입니다.
기존 사용자는 앱을 삭제하지 말고 새 APK를 열어 **업데이트 설치**하세요.
패키지 `kr.bloodnote.app`, 기존 서명, 저장 키, 암호화 방식과 데이터 형식을 유지합니다.
새로 설치한 앱은 기록과 계획이 모두 0건입니다.

- Android 8(API 26) 이상. 증명서 PDF 읽기는 Android 15(API 35) 이상.
- versionName `2.1.1`, versionCode `17`.
- 이번부터 작은 월간 달력만 제공합니다. 기존 Large 설치에도 같은 서명의 이 APK로 업데이트할 수 있습니다.

## 2.1.1 변경 사항

- 잔여량 카드의 `90~429mL 구간`처럼 숫자 범위를 반복하던 배지를 제거했습니다.
- 설정 → **화면 표시**에 `잔여량 구간별 표시`와 `헌혈 완료일 강조` 스위치를 추가했습니다. 두 항목은 독립적으로 동작하며 기본값은 켜짐입니다.
- 끈 상태도 재실행 및 암호화 백업 복원 후 유지됩니다. 표시를 바꾸어도 헌혈 기록·계획·계산 기준·계산 결과는 바뀌지 않습니다. 인터넷을 사용하지 않습니다.
- 잔여량 구간별 표시를 끄면 기본 초록 카드로 돌아가고 계산량 충족 설명이 사라집니다. 완료일 강조를 끄면 파란 배경·체크·진한 완료 표시가 사라지며 기존 완료 글자와 날짜 팝업은 유지됩니다.

## 화면 표시와 첫 화면

- 실제 헌혈 기록이 있는 달력 날짜는 파란 배경과 ✓로 표시하고, 해당 종류의 `완료`를 진하게 표시합니다. 날짜가 지났다는 이유만으로 계획을 완료로 표시하지 않습니다. 주말·공휴일의 붉은 날짜와 공휴일명은 유지합니다.
- 잔여량 카드의 배경색과 구간 설명이 함께 바뀝니다. 기본값은 아래와 같으며, 계산 기준에서 종류별 계산량을 바꾸면 구간과 충족 종류도 그 값에 맞춰 바뀝니다.

| 잔여 계산량 | 표시 |
| --- | --- |
| 44mL 이하 | 붉은색 · 최소 계산량 미만 |
| 45~89mL | 갈색 계열 · 혈장 계산량 충족 |
| 90~429mL | 파란색 · 혈장·혈소판·혈소판 혈장 계산량 충족 |
| 430mL 이상 | 초록색 · 네 종류 계산량 충족 |

이 표시는 계산량만 비교합니다. 간격·횟수를 포함한 조건은 다음 헌혈 예상일과 날짜 팝업에서 확인합니다. 입력 기록이 없으면 중립색과 `—`를 표시합니다.

설정 상단의 **첫 화면 설정**에서 한눈에 보기, 일정 시뮬레이터, 헌혈 기록 중 선택할 수 있습니다. 선택 즉시 기존 암호화 저장소에 저장되며 백업에도 포함됩니다. 앱을 완전히 종료한 뒤 다시 열면 선택한 화면으로 시작합니다. 실행 중 화면 복원은 보던 화면을 유지합니다. 기존 앱 및 첫 화면 설정이 없는 이전 백업은 한눈에 보기로 시작합니다.

뒤로가기는 팝업을 먼저 닫고, 다른 화면에서는 설정한 첫 화면으로 돌아갑니다. 첫 화면에서는 기존의 두 번 뒤로가기로 종료합니다. 로고를 누르면 계속 한눈에 보기로 이동합니다.

## 앞으로의 버전 규칙

이번 배포는 사용자 지정 `v2.1.1`입니다. 다음부터 아래 규칙을 적용하고, Android 설치용 versionCode는 매 배포마다 증가시킵니다.

| 변경 내용 | 버전 예시 |
| --- | --- |
| 사소한 버그·오타·화면 미세 조정 | `v2.1.1` → `v2.1.2` |
| 새로운 계산 기능이나 메뉴 추가 | `v2.1.1` → `v2.2.0` |
| 디자인·구조의 전면 개편 | `v2.1.1` → `v3.0.0` |

## 날짜 팝업

1. 7열의 작은 월간 달력에서 날짜를 누릅니다. 주간·월간 전환은 제거했습니다.
2. 팝업에 날짜·요일·공휴일명과 네 종류가 나옵니다. 위에는 전혈/혈장, 아래에는 혈소판/혈소판 혈장이 배치됩니다.
3. 종류를 누르면 예상 잔여량과 제한 이유를 보여 줍니다. `선택 완료`를 눌러야 계획에 저장됩니다.
4. 저장된 날짜를 다시 누르면 기존 종류가 선택됩니다. 다른 종류로 변경하거나 `계획 취소`를 누를 수 있습니다.
5. 예정일이 오늘이거나 지나면 실제 헌혈 여부에 따라 기록으로 남기거나 계획을 취소합니다. 자동으로 완료 처리하지 않습니다.

계산 조건을 충족하지 않는 가정도 시뮬레이터에서 검토할 수 있습니다. 이 경우 붉은 제한 표시와 이유를 확인한 뒤 `제한 있는 가정으로 저장`을 명시적으로 눌러야 합니다. 실제 예약 기능이 아닙니다.

잔여량 기준일은 한국 시간의 오늘로 고정합니다. 상하단 월 이동, 기록 5건 단위 표시, PDF 검토, 백업, 암호화 저장과 수동 공휴일 갱신을 유지합니다.

## 오프라인·개인정보

화면, 계산, 계획, PDF 분석과 암호화는 기기에서 처리합니다. 공휴일은 사용자가 🔃를 누르고 이번 갱신의 인터넷 사용을 허용했을 때만 가져옵니다. 앱에 광고·분석 SDK는 없습니다.
외부 출처 링크를 누르면 브라우저가 열립니다. 이전 개인용 웹앱 링크는 배포본에서 제거했습니다.

앱 저장 데이터는 Android Keystore 기반 AES-GCM으로 보호합니다. 내보내는 백업은 사용자 비밀번호에서 키를 만든 AES-GCM 암호문입니다. 원본 PDF는 앱에 복사하거나 배포하지 않습니다. 앱 삭제나 데이터 삭제 전에 백업하세요.

## 소스와 빌드

앱 실행에 별도 JavaScript 라이브러리, CSS 프레임워크, Gradle 플러그인은 사용하지 않습니다.

- `assets/`: HTML/CSS/JavaScript, 계산 엔진, 로컬 공휴일 자료·라이선스
- `src/kr/bloodnote/app/`: Android WebView, 보안 저장, PDF 읽기·분석
- `res/`: Android 리소스와 직접 작성한 벡터 아이콘
- `tools/generate_icons.py`: 외부 이미지 없이 도형 좌표에서 아이콘 재생성
- `tests/`: 합성 데이터로 동작을 검사하는 개발용 코드

빌드 환경: JDK 17 이상, Python 3, Android SDK platform 36 및 build-tools 36.0.0.
SDK 위치를 `ANDROID_HOME`으로 설정하고 프로젝트 폴더에서 실행합니다.

```sh
python3 tools/generate_icons.py
node --test tests/*.test.mjs
node tests/android-shell-smoke.mjs
python3 build.py
```

`build.py`는 표준 SDK 설치 경로와 기존 작업 환경의 SDK 경로를 지원합니다.
별도의 Python/Node 패키지 설치 없이 기본 빌드·JS 검사가 가능합니다.
선택 사항인 실제 PDF 비교 검사만 PC에 `pypdfium2`와 `pdftotext`가 필요합니다. 해당 도구는 APK/ZIP에 포함하지 않습니다.

PRIVATE 원본은 기존 `signing/release.jks`와 `signing/password.txt`로 빌드합니다.
GitHub 소스만 빌드하면 **새 서명키가 로컬에 생성**됩니다. 새 키로 만든 APK는 기존 배포 APK 위에 업데이트 설치할 수 없습니다. 기존 사용자에게 업데이트를 배포할 제작자는 원래 키를 공개 저장소 밖에서 보관하고 사용해야 합니다.
향후 업데이트는 versionCode를 올리고 같은 패키지·서명·로컬 화면 출처를 유지하세요.
